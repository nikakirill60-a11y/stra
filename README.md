# ⚔️ Завоевание Европы

Пошаговая стратегия (в духе Risk) на карте Европы: **45 стран**, настоящие **флаги из интернета**, броски кубиков, ИИ-соперники и бонусы за полные регионы.

![Статус](https://img.shields.io/badge/играбельно-да-brightgreen) ![Платформа](https://img.shields.io/badge/Windows-x64-blue) ![Флаги](https://img.shields.io/badge/флаги-flag-icons_(MIT)-yellow)

## 🎮 Как играть

1. Запустите **`dist/EuropeStrategy.exe`** (Windows) — игра откроется в браузере.
   Интернет не нужен: все флаги и файлы вшиты внутрь exe.
2. Или запустите без сборки: `npm start` (нужен Node.js) — откроется `http://127.0.0.1:7777/`.

### Правила
- **Цель** — захватить все страны Европы.
- В начале хода вы получаете **резервы** (армии): `макс(3, страны ÷ 3)` + бонусы за регионы.
- **Размещение** — кликайте по своим странам (+1 армия за клик).
- **Атака** — выберите свою страну (2+ армии), кликните соседнюю вражескую.
  Атакующий бросает до 3 кубиков, защитник — до 2; при равенстве побеждает защитник.
- **Захват** — когда у защитника кончаются армии, страна переходит вам.
- **Переброс** — двигайте армии между своими соседними странами.
- **Регионы**: Скандинавия, Западная Европа, Юг Европы, Балканы, Балтика и Восток —
  полный контроль даёт доп. резервы каждый ход.
- Держава без стран выбывает. Последний выживший побеждает.

## 🚩 Флаги

Флаги скачаны из интернета из пакета [flag-icons](https://www.npmjs.com/package/flag-icons) (MIT)
и встроены в игру в виде SVG (base64). Перескачать: `npm run flags`.

## 🛠 Сборка .exe

```bash
npm install          # postject (вшивание блоба)
npm run build:win    # готовый файл: dist/EuropeStrategy.exe (~92 МБ)
```

Как это работает (Node.js SEA — Single Executable Application):
1. `tools/build-win.mjs` скачивает официальные бинарники Node.js 22.20.0 (Linux + Windows)
   из пакета `nodejs-wheel-binaries` (PyPI);
2. склеивает сервер `server.js` и все файлы `game/` в один `dist/sea-bundle.cjs`;
3. генерирует SEA-блоб и вшивает его в копию `node.exe` утилитой `postject` (npm);
4. на выходе — настоящий Windows PE `dist/EuropeStrategy.exe`, который поднимает
   локальный сервер и открывает игру в браузере.

## 📁 Структура

```
server.js              — локальный сервер игры (дисковый / встроенный режим)
game/
  index.html           — интерфейс
  style.css            — тёмная тема
  game.js              — карта, бой, ИИ, фазы
  flags.js             — 45 флагов (сгенерировано из интернета)
tools/
  download-flags.mjs   — скачать флаги с npm (flag-icons)
  build-win.mjs        — сборка Windows .exe
  smoke-test.mjs       — смоук-тест игровой логики (node tools/smoke-test.mjs)
dist/
  EuropeStrategy.exe   — готовая игра для Windows
```

## ✅ Проверки

node tools/smoke-test.mjs   # игровая логика без браузера
